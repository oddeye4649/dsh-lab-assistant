## 下载与安装

- 附件：`{{ASSET}}`（SHA-256 `{{SHA256}}`）
- **DSH**：把这个 `.tgz` 交给 DSH 桌面端的 `plugin_manager` 安装，或用同一仓库链接重装；装完**完全退出 DSH（含托盘）再打开**。
- **WorkBuddy**：在 clone 的目录执行 `git pull --ff-only`，重启桌面启动器与 WorkBuddy；详见仓库 `INSTALL_WORKBUDDY.md`。
- **查当前版本**：对话里说「用实验助手读一下状态」，看返回的 `version`；最新版本号看 Releases 页面第一条。
- 数据目录默认 `~/.dsh/lab-assistant`，**升级不会覆盖**已有实验档案、模板与经验。
- 桌宠与「实验助手」面板仅 Windows；Mac / Linux 只能用 MCP 对话工具。

各版本的改动内容见上方 CHANGELOG 小节；完整发布规则见 `docs/RELEASE.md`。
