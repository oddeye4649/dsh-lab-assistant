# 桌宠动画帧图片需求与提示词

程序会自动扫描 `assets/pet/` 下所有 PNG：同名加 `_1`、`_2`… 就当成一组动画帧循环播放，单张同名图也能用。**所有图只做朝右的版本即可，朝左由程序镜像**，不需要另外出图。

## 通用规范（每条提示词都适用）

- 尺寸 `512 × 512`，PNG，透明背景
- 角色与现有素材完全一致：Q 版蓝发少女、鱼鳍状耳朵、白色蕾丝头饰、深蓝连衣裙配鲸鱼图案白围裙、蓝瞳、头顶一根呆毛
- 角色水平居中，脚底基线距画面底边约 24px，**同组各帧位置必须完全一致**
- 不要阴影、背景、文字、边框；不要改发型、配色、脸型、衣服
- 建议用 `assets/pet/drink_1.png` 或任意已生成帧作参考图（图生图）保证一致性

## 一、基础动作（5 组）

| 文件名 | 帧数 | 触发时机 |
| --- | --- | --- |
| `idle_1.png` ~ `idle_4.png` | 4 | 待机：呼吸、眨眼、裙摆微动 |
| `swim_1.png` ~ `swim_8.png` | 8（两张 2×2） | 走动：完整两步循环（程序会左右镜像） |
| `dash_1.png` ~ `dash_3.png` | 3（一张 1×3） | 引导冲刺：被叫去某个窗口时的快速移动 |
| `point_1.png`、`point_2.png` | 2 | 指引窗口/控件：抬手指向目标 |
| `happy_1.png` ~ `happy_4.png` | 4 | 新建实验、报告生成成功 |
| `confused_1.png`、`confused_2.png` | 2 | 报告生成失败、环境异常 |

### 1.1 待机 idle

```text
参考图中的 Q 版蓝发少女角色（鱼鳍状耳朵、蓝白女仆风连衣裙、大眼睛），生成同一角色的 4 帧待机动画序列，512×512 透明背景 PNG。
第 1 帧：自然站立，双手轻提裙摆，微微吸气，身体上浮约 2%。
第 2 帧：呼气下沉，肩膀略放松，头发和裙摆轻微向下。
第 3 帧：同第 1 帧姿态但眼睛闭合（眨眼），嘴角带浅浅微笑。
第 4 帧：同第 2 帧姿态，眼睛睁开。
要求：四帧角色大小、位置、脚底基线完全一致，只有呼吸幅度与眨眼不同；不要阴影、背景、文字；保持与原角色一致的线条粗细和上色风格。
```

### 1.2 走动 swim（8 帧，两张 2×2）

一张图放不下 8 帧，分两张生成。**两张图的角色大小、朝向、脚底基线必须一致**，否则动画会一跳一跳。

第一张（第 1~4 帧，右脚迈步）：

```text
参考图中的 Q 版蓝发少女角色（蓝发、鱼鳍状耳朵、白色蕾丝头饰、深蓝连衣裙配鲸鱼图案白围裙、蓝瞳、头顶一根呆毛），生成 4 帧“向右轻快走路”的动画序列，2×2 排布在 512×512 的单格里，整张图 1024×1024，透明背景 PNG。
整体朝向：身体正面偏右约 20 度，始终朝画面右侧走。
第 1 帧（接触）：右脚向前迈出、脚尖先着地，左脚在后脚掌抬起；双臂前后自然摆动（右臂前、左臂后）；裙摆和长发向左后方飘；呆毛向后倒。
第 2 帧（下沉）：重心落到右脚，双膝微屈，身体比第 1 帧低约 3%；裙摆回落、稍微收拢；手臂摆到身体两侧。
第 3 帧（经过）：左脚收拢经过右脚旁，双脚最接近；身体升到最高点；裙摆收窄、头发轻轻上浮；手臂贴身。
第 4 帧（推离）：左脚向前迈出、脚掌蹬地，右脚在后脚跟抬起；手臂交换（左臂前、右臂后）；裙摆和长发向右后方飘。
要求：四帧角色比例、脸型、服装细节完全一致；脚底基线在同一水平线（第 2、3 帧可上下浮动不超过角色高度的 3%）；不要阴影、背景、文字、速度线。
```

第二张（第 5~8 帧，左脚迈步，动作与第一张镜像对称但人物仍朝右）：

```text
参考图中的 Q 版蓝发少女角色（蓝发、鱼鳍状耳朵、白色蕾丝头饰、深蓝连衣裙配鲸鱼图案白围裙、蓝瞳、头顶一根呆毛），生成 4 帧“向右轻快走路”的后半步循环，2×2 排布在 512×512 的单格里，整张图 1024×1024，透明背景 PNG。
整体朝向：身体正面偏右约 20 度，始终朝画面右侧走；角色大小、位置、脚底基线与参考图第一张完全一致。
第 5 帧（接触）：左脚向前迈出、脚尖先着地，右脚在后脚掌抬起；左臂后、右臂前；裙摆和长发向右后方飘。
第 6 帧（下沉）：重心落到左脚，双膝微屈，身体比第 5 帧低约 3%；裙摆回落；手臂摆到身体两侧。
第 7 帧（经过）：右脚收拢经过左脚旁，双脚最接近；身体升到最高点；裙摆收窄、头发上浮；手臂贴身。
第 8 帧（推离）：右脚向前迈出、脚掌蹬地，左脚在后脚跟抬起；手臂交换（右臂后、左臂前）；裙摆和长发向左后方飘。
要求：与第一张四帧的角色比例、朝向、基线完全一致，能无缝循环衔接；不要阴影、背景、文字、速度线。
```

## 二、待机小动作（10 组，做几组都行）

桌宠空闲时每隔约 20~60 秒随机做一个，做完回到待机。**只要文件名对，程序自动识别，不需要改代码**。建议每组 4 帧（最少 2 帧）。

| 文件名 | 动作 | 帧数 |
| --- | --- | --- |
| `drink_1..4.png` | 喝咖啡/奶茶 | 4 |
| `typing_1..4.png` | 敲键盘 | 4 |
| `read_1..3.png` | 看书 | 3 |
| `stretch_1..4.png` | 伸懒腰 | 4 |
| `wave_1..3.png` | 挥手打招呼 | 3 |
| `sleep_1..3.png` | 打瞌睡 | 3 |
| `snack_1..4.png` | 吃零食 | 4 |
| `music_1..3.png` | 戴耳机听歌 | 3 |
| `wipe_1..3.png` | 擦汗 | 3 |
| `spin_1..4.png` | 原地转圈 | 4 |

## 三、接入方式

1. 把生成的图按上表命名放进 `assets/pet/`；
2. 重新 `npm pack` 并安装，或直接替换已安装目录里的 `assets/pet/` 后重启 DSH；
3. 想关掉待机小动作和说话，在“实验助手”面板 → 桌宠设置里取消“待机动画与说话”。

没有这些图也能正常用：程序会用呼吸缩放、走动小跳、左右镜像等内置动效兜底。
