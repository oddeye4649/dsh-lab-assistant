# 桌宠台词与触发时机

所有台词都在本地播放，**不消耗模型 token**。同一时间只显示一个气泡；新台词会直接替换旧的。

> **称呼替换**：下面所有台词里的「主人」都会自动替换成面板「桌宠设置 → 称呼」里填的内容。例如把称呼改成「小明」，就会说「小明，今天做哪个实验呀？」。默认称呼就是「主人」，此时原样显示。事件台词与引导台词同样走这套替换。

## 一、待机小动作台词（10 组，动作开始时随机一句）

桌宠空闲时每 20~60 秒随机做一个动作，动作一开始就说对应的话，气泡显示约 5 秒。

| 动作 | 台词 |
| --- | --- |
| 喝咖啡 | 「喝口咖啡，提提神～」<br>「这个马克杯是鲸鱼图案的，可爱吧？」 |
| 敲键盘 | 「我在帮你整理实验数据呢～」<br>「键盘敲起来哒哒哒，好解压。」 |
| 看书 | 「翻翻实验指导书，别漏了步骤。」<br>「书里这段好像老师强调过。」 |
| 伸懒腰 | 「坐久了要伸个懒腰～」<br>「主人也起来活动一下吧。」 |
| 挥手 | 「主人，看这里～」<br>「我在这儿呢！」 |
| 打瞌睡 | 「呼……就眯一小会儿……」<br>「啊！我没睡着！」 |
| 吃饼干 | 「偷偷吃块饼干，嘿嘿。」<br>「主人要不要来一块？」 |
| 戴耳机听歌 | 「听首歌，脑子清醒多了。」<br>「这个节奏好上头～」 |
| 擦汗 | 「做实验做出汗了……」<br>「擦擦汗，继续加油。」 |
| 转圈 | 「转个圈，心情变好啦～」<br>「看我转得圆不圆？」 |

## 二、待机闲聊（8 条，约每 40~90 秒一句）

## 三、事件台词（由插件在本地触发）

这些由插件在实验流程里主动调用桌面进程说，和"待机动画与说话"开关无关，始终生效。

| 触发事件 | 桌宠状态 | 台词 | 来源 |
| --- | --- | --- | --- |
| 新建实验档案 | 开心 | 「新实验档案建好啦，主人加油～」 | 面板「创建实验档案」或工具建档案 |
| 报告生成成功 | 开心 | 「报告生成好啦，记得核对【待补】的地方～」 | 面板「生成报告」或工具生成 |
| 报告生成失败 | 疑惑 | 「报告生成出错了，我看看哪里不对…」 | 生成报告抛错时 |

## 四、桌面引导台词

| 触发事件 | 桌宠状态 | 台词 |
| --- | --- | --- |
| `lab_desktop_guide` 定位到软件窗口/控件 | 指向 + 冲刺到位 | 调用时传入的 `text`；**没传就用默认**「主人，看这里～」 |

## 五、开关与自定义

- 面板 →「桌宠设置」→ **待机动画与说话**：
  - 关闭后：不再自动播小动作、不再说动作台词和待机闲聊；
  - 事件台词、引导台词仍然保留，因为它们只在实验流程里出现。
- 通过本机接口自定义一句：
  ```json
  POST /pet?token=…  { "action": "say", "text": "主人，该保存实验记录了", "durationMs": 6000 }
  ```
- 动作与台词是松耦合的：以后新增动作只要文件名对上（如 `stretch_1..4.png`），台词表里加一行即可。

## 六、台词总量

- 待机小动作：10 组 × 2 句 = **20 句**
- 待机闲聊：**8 句**
- 事件台词：**3 句**
- 引导默认台词：**1 句**
- 合计固定台词 **32 句**，另加引导调用时可传入的任意文本。
